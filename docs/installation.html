📥 مرحله ۱: آپلود فایل‌ها

  1. تمام فایل‌های پروژه را در ریشه زیردامنه brandmaker.ea-fixer.ir آپلود کنید (File Manager یا FTP)
  2. دقت کنید فایل .htaccess هم آپلود شده باشد (در File Manager گزینه Show Hidden Files را فعال کنید)

🗄️ مرحله ۲: ساخت دیتابیس

  1. در cPanel به بخش MySQL Databases بروید
  2. یک دیتابیس جدید بسازید (مثلاً cpaneluser_brandmaker)
  3. یک کاربر دیتابیس بسازید و رمز قتی انتخاب کنید
  4. کاربر را به دیتابیس اضافه کنید با ALL PRIVILEGES

🚀 مرحله ۳: اجرای نصب‌کننده

  1. در مرورگر به https://brandmaker.ea-fixer.ir/install.php بروید
  2. بررسی الزامات به صورت خودکار انجام می‌شود — در صورت سبز بودن همه موارد، ادامه دهید
  3. اطلاعات دیتابیس (نام، کاربر، رمز) و حساب مدیر را وارد کنید
  4. روی «اجرای نصب» کلیک کنید — جداول به صورت خودکار ساخته می‌شوند

✅ پس از نصب: فایل config.local.php ساخته می‌شود و install.lock نصب را قفل می‌کند.

🔐 مرحله ۴: اقدامات امنیتی پس از نصب

  • در صورت اطمینان از کارکرد، فایل install.php را از هاست حذف کنید
  • SSL را از بخش SSL/TLS Status فعال کنید (AutoSSL)
  • مطمئن شوید نسخه PHP روی 8.0+ تنظیم شده است

🏷️ مرحله ۵: ساخت اولین سایت برند

  1. وارد پنل /admin شوید
  2. ابتدا از تنظیمات، اطلاعات نمایندگی (نام، لوگو، تلفن‌ها، آدرس‌ها) را کامل کنید
  3. از مدیریت برندها ← برند جدید، نام فارسی/انگلیسی + لوگو + دامنه را وارد کنید
  4. فرآیند ساخت ۸ مرحله‌ای به صورت خودکار اجرا می‌شود (تحلیل لوگو، تولید محتوا با AI، مقالات، سئو)
  5. از خروجی و استقرار فایل ZIP سایت برند را دانلود و روی زیردامنه برند آپلود کنید
