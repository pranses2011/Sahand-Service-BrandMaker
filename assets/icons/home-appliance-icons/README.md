# 📦 پک آیکون‌های اختصاصی لوازم خانگی

پک اختصاصی تولیدشده توسط تیم سهند — ۱۰۳ آیکون SVG خاص صنعت تعمیرات لوازم خانگی
(یخچال، لباسشویی، ظرفشویی، کولر، پکیج، مایکروویو، جاروبرقی و...).

## 📥 دانلود
- ✅ نیازی به دانلود خارجی نیست — همه آیکون‌ها داخل همین پوشه ریپو موجودند (103 فایل SVG)
- 🔄 برای بروزرسانی، ریپو را clone/pull کنید

## 🔒 نکات
- ساخته‌شده برای این سیستم — فرمت استاندارد SVG با viewBox=24x24
- قابل استفاده از طریق: `GET /api/icon/&#123;pack&#125;/&#123;name&#125;` یا پنل مدیریت → آیکون‌ها
