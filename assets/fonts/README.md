### 🔗 لینک مستقیم فایل (CDN) — بدون مراجعه به سایت

برای فونت‌های GitHub-محور می‌توانید مستقیم از CDN دانلود کنید (مثال وزیرمتن):

```
https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/fonts/ttf/Vazirmatn-Regular.ttf
https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/fonts/ttf/Vazirmatn-Bold.ttf
https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/fonts/webfonts/Vazirmatn-Regular.woff2
```

## 📥 نحوه افزودن فایل‌های فونت

فایل‌های باینری فونت (`.ttf`, `.woff2`) به دلایل حجم و لایسنس در ریپو نیستند و باید از طریق
**پنل مدیریت → فونت‌ها** آپلود شوند. سیستم به صورت خودکار:

1. فایل را در مسیر صحیح (`fa/<slug>/` یا `en/<slug>/`) ذخیره می‌کند
2. فایل `@font-face` از قبل در `assets/css/fonts.css` تعریف شده است
3. سایت‌های برند فونت‌ها را از سرور سایت ساز فراخوانی می‌کنند (بدون CDN خارجی)

## 📋 نام‌گذاری فایل‌ها

```
fa/vazirmatn/vazirmatn-regular.woff2
fa/vazirmatn/vazirmatn-bold.woff2
en/inter/inter-regular.woff2
```

قالب: `<lang>/<slug>/<slug>-<weight>.<ext>` — وزن‌ها: `thin` `light` `regular` `medium` `demibold` `bold` `extrabold` `black`
