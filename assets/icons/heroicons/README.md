# 📦 پک هیروآیکون (Heroicons)

این پک با زیرمجموعه‌ای از آیکون‌های پرکاربرد ارائه می‌شود (8 آیکون موجود).
پک کامل (۳۰۰+ آیکون) را از لینک‌های رسمی زیر دانلود و از طریق
**پنل مدیریت → آیکون‌ها → ایمپورت پک** بارگذاری کنید.

## 📥 لینک‌های دانلود رسمی

| منبع | لینک |
|------|------|
| 🌐 سایت رسمی (مرور + دانلود تک‌تک) | [https://heroicons.com](https://heroicons.com) |
| 📦 مخزن GitHub (کد منبع) | [https://github.com/tailwindlabs/heroicons](https://github.com/tailwindlabs/heroicons) |
| 🚀 **دانلود مستقیم آخرین نسخه (ZIP)** | [**https://github.com/tailwindlabs/heroicons/releases/latest**](https://github.com/tailwindlabs/heroicons/releases/latest) |

> ⚡ **سریع‌ترین راه:** روی لینک «دانلود مستقیم» بزنید — در صفحه بازشده، فایل ZIP آماده
> آخرین نسخه (مثل `remixicon-4.x.x.zip`) در پایین است. فایل `icons/` داخل آن را
> از طریق پنل ایمپورت کنید.

## ℹ️ مشخصات

| مورد | مقدار |
|------|-------|
| تعداد آیکون پک کامل | ۳۰۰+ |
| لایسنس | MIT (کاملاً آزاد) |
| ویژگی | ساخته تیم Tailwind CSS — سبک و مدرن (Outline و Solid) |
| موجود در این ریپو | 8 آیکون پرکاربرد |

## 🔒 نکات
- آیکون‌ها روی سرور سایت ساز ذخیره می‌شوند (بدون CDN خارجی)
- فرمت استاندارد: SVG با viewBox=24x24
