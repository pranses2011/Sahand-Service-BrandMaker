# 📦 پک فسفر آیکون (Phosphor)

این پک با زیرمجموعه‌ای از آیکون‌های پرکاربرد ارائه می‌شود (8 آیکون موجود).
پک کامل (۹۰۰۰+ آیکون) را از لینک‌های رسمی زیر دانلود و از طریق
**پنل مدیریت → آیکون‌ها → ایمپورت پک** بارگذاری کنید.

## 📥 لینک‌های دانلود رسمی

| منبع | لینک |
|------|------|
| 🌐 سایت رسمی (مرور + دانلود تک‌تک) | [https://phosphoricons.com](https://phosphoricons.com) |
| 📦 مخزن GitHub (کد منبع) | [https://github.com/phosphor-icons/web](https://github.com/phosphor-icons/web) |
| 🚀 **دانلود مستقیم آخرین نسخه (ZIP)** | [**https://github.com/phosphor-icons/web/releases/latest**](https://github.com/phosphor-icons/web/releases/latest) |

> ⚡ **سریع‌ترین راه:** روی لینک «دانلود مستقیم» بزنید — در صفحه بازشده، فایل ZIP آماده
> آخرین نسخه (مثل `remixicon-4.x.x.zip`) در پایین است. فایل `icons/` داخل آن را
> از طریق پنل ایمپورت کنید.
