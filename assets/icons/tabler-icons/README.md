# 📦 پک تبلر آیکون (Tabler Icons)

این پک با زیرمجموعه‌ای از آیکون‌های پرکاربرد ارائه می‌شود (8 آیکون موجود).
پک کامل (۵۷۰۰+ آیکون) را از لینک‌های رسمی زیر دانلود و از طریق
**پنل مدیریت → آیکون‌ها → ایمپورت پک** بارگذاری کنید.

## 📥 لینک‌های دانلود رسمی

| منبع | لینک |
|------|------|
| 🌐 سایت رسمی (مرور + دانلود تک‌تک) | [https://tabler.io/icons](https://tabler.io/icons) |
| 📦 مخزن GitHub (کد منبع) | [https://github.com/tabler/tabler-icons](https://github.com/tabler/tabler-icons) |
| 🚀 **دانلود مستقیم آخرین نسخه (ZIP)** | [**https://github.com/tabler/tabler-icons/releases/latest**](https://github.com/tabler/tabler-icons/releases/latest) |

> ⚡ **سریع‌ترین راه:** روی لینک «دانلود مستقیم» بزنید — در صفحه بازشده، فایل ZIP آماده
> آخرین نسخه (مثل `remixicon-4.x.x.zip`) در پایین است. فایل `icons/` داخل آن را
> از طریق پنل ایمپورت کنید.
