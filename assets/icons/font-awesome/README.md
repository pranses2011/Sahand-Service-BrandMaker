# 📦 پک فونت اوسوم (Font Awesome)

این پک با زیرمجموعه‌ای از آیکون‌های پرکاربرد ارائه می‌شود (8 آیکون موجود).
پک کامل (۲۰۰۰+ (نسخه رایگان ۶) آیکون) را از لینک‌های رسمی زیر دانلود و از طریق
**پنل مدیریت → آیکون‌ها → ایمپورت پک** بارگذاری کنید.

## 📥 لینک‌های دانلود رسمی

| منبع | لینک |
|------|------|
| 🌐 سایت رسمی (مرور + دانلود تک‌تک) | [https://fontawesome.com/icons](https://fontawesome.com/icons) |
| 📦 مخزن GitHub (کد منبع) | [https://github.com/FortAwesome/Font-Awesome](https://github.com/FortAwesome/Font-Awesome) |
| 🚀 **دانلود مستقیم آخرین نسخه (ZIP)** | [**https://github.com/FortAwesome/Font-Awesome/releases/latest**](https://github.com/FortAwesome/Font-Awesome/releases/latest) |

> ⚡ **سریع‌ترین راه:** روی لینک «دانلود مستقیم» بزنید — در صفحه بازشده، فایل ZIP آماده
> آخرین نسخه (مثل `remixicon-4.x.x.zip`) در پایین است. فایل `icons/` داخل آن را
> از طریق پنل ایمپورت کنید.

## ℹ️ مشخصات

| مورد | مقدار |
|------|-------|
| تعداد آیکون پک کامل | ۲۰۰۰+ (نسخه رایگان ۶) |
| لایسنس | CC BY 4.0 (آیکون‌ها) + MIT (کد) |
| ویژگی | محبوب‌ترین مجموعه آیکون دنیا — ۶ سبک مختلف |
| موجود در این ریپو | 8 آیکون پرکاربرد |

## 🔒 نکات
- آیکون‌ها روی سرور سایت ساز ذخیره می‌شوند (بدون CDN خارجی)
- فرمت استاندارد: SVG با viewBox=24x24
