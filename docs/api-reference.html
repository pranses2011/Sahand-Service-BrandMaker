🔌 راهنمای API داخلی سایت ساز

آدرس پایه: https://brandmaker.ea-fixer.ir/api

🔑 احراز هویت

تمام اندپوینت‌ها (به جز مسیرهای عمومی) نیاز به کلید API در هدر دارند:

X-API-Key: bmk_یکلید_نمونه...

کلید هر برند از «ویرایش برند ← تب API» قابل مشاهده است. محدودیت: ۱۲۰ درخواست در دقیقه برای هر IP.

🌐 اندپوینت‌های سایت برند

متدمسیرتوضیح
GETbrand/{id}اطلاعات کامل برند: لوگو، پالت رنگ، تماس‌ها، سئو
GETbrand/{id}/page/{type}محتوای صفحه (home, services, ...)
GETbrand/{id}/articles?page=1لیست مقالات با صفحه‌بندی
GETbrand/{id}/article/{slug}مقاله تکی + مرتبط‌ها
GETbrand/{id}/devicesدستگاه‌های فعال برند
GETbrand/{id}/faqsسوالات متداول
GETbrand/{id}/error-codes?q=E1&device=...کدهای خطا + جستجو
GETbrand/{id}/menu/{header|footer}منوی درختی
GETbrandsلیست عمومی برندهای منتشرشده
GETsettingsتنظیمات عمومی (نیاز به کلید)
GETfontsلیست ۳۰ فونت + URL فایل CSS

🤖 اندپوینت‌های موتور AI

متدمسیرورودی
POSTai/generate-content{brand_id, type: brand_intro|brand_history|...}
POSTai/generate-article{brand_id, topic_type, device_key, auto_save}
POSTai/generate-seo{brand_id, page_type, content}
POSTai/generate-brand-info{brand_id} — پکیج کامل
POSTai/generate-faq{brand_id, count}
POSTai/analyze-keywords{text, focus_keyword, brand_id}
POSTai/check-uniqueness{content, brand_id}
POSTai/suggest-improvements{content, title, focus_keyword}
GETai/templatesخلاصه قالب‌های محتوایی
GETai/knowledge/{brand}دانش برند (مثلاً samsung)

🧪 نمونه کد PHP

// دریافت اطلاعات برند
$ch = curl_init('https://brandmaker.ea-fixer.ir/api/brand/1');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_HTTPHEADER => ['X-API-Key: bmk_YOUR_KEY'],
]);
$response = json_decode(curl_exec($ch), true);
