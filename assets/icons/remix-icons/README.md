# 📦 پک رمیکس آیکون (Remix Icon)

این پک با زیرمجموعه‌ای از آیکون‌های پرکاربرد ارائه می‌شود (8 آیکون موجود).
پک کامل (۳۰۰۰+ آیکون) را از لینک‌های رسمی زیر دانلود و از طریق
**پنل مدیریت → آیکون‌ها → ایمپورت پک** بارگذاری کنید.

## 📥 لینک‌های دانلود رسمی

| منبع | لینک |
|------|------|
| 🌐 سایت رسمی (مرور + دانلود تک‌تک) | [https://remixicon.com](https://remixicon.com) |
| 📦 مخزن GitHub (کد منبع) | [https://github.com/Remix-Design/RemixIcon](https://github.com/Remix-Design/RemixIcon) |
| 🚀 **دانلود مستقیم آخرین نسخه (ZIP)** | [**https://github.com/Remix-Design/RemixIcon/releases/latest**](https://github.com/Remix-Design/RemixIcon/releases/latest) |

> ⚡ **سریع‌ترین راه:** روی لینک «دانلود مستقیم» بزنید — در صفحه بازشده، فایل ZIP آماده
> آخرین نسخه (مثل `remixicon-4.x.x.zip`) در پایین است. فایل `icons/` داخل آن را
> از طریق پنل ایمپورت کنید.

- آیکون‌ها روی سرور سایت ساز ذخیره می‌شوند (بدون CDN خارجی)
