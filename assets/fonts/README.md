# 🔤 پوشه فونت‌ها

| پوشه | محتوا |
|------|-------|
| `fa/` | ۲۰ فونت فارسی |
| `en/` | ۱۰ فونت انگلیسی |

## 📥 نحوه افزودن فایل‌های فونت
فایل‌های باینری فونت (`.ttf`, `.woff2`) به دلایل حجم و لایسنس در ریپو نیستند و باید از طریق
**پنل مدیریت → فونت‌ها** آپلود شوند. سیستم به صورت خودکار:

1. فایل را در مسیر صحیح (`fa/<slug>/` یا `en/<slug>/`) ذخیره می‌کند
2. فایل `@font-face` از قبل در `assets/css/fonts.css` تعریف شده است
3. سایت‌های برند فونت‌ها را از سرور سایت ساز فراخوانی می‌کنند (بدون CDN خارجی)

## 📋 نام‌گذاری فایل‌ها
```
fa/vazirmatn/vazirmatn-regular.woff2
fa/vazirmatn/vazirmatn-bold.woff2
en/inter/inter-regular.woff2
```
