📜 راهنمای واسط Google Apps Script برای تلگرام

در زمان تحریم سرورهای تلگرام، ارسال مستقیم ممکن است خطا دهد. این واسط درخواست را از سرور گوگل به تلگرام می‌فرستد.

⚠️ الزام مهم سند: Bot Token و Chat ID داخل اسکریپت ذخیره نمی‌شوند — با هر درخواست به عنوان پارامتر ارسال می‌شوند و از تنظیمات تلگرام در پنل سایت ساز خوانده می‌شوند.

🔧 راه‌اندازی گام به گام

  1. به script.google.com بروید و با حساب گوگل وارد شوید
  2. روی پروژه جدید (New Project) کلیک کنید
  3. محتوای فایل google-apps-script.js (از پوشه assets/scripts یا پایین همین صفحه) را در ویرایشگر کپی کنید
  4. روی Deploy ← New deployment کلیک کنید
  5. نوع را Web app انتخاب کنید:
    • Execute as: Me (من)
    • Who has access: Anyone (هر کسی)
  6. روی Deploy کلیک و مجوزها را تأیید کنید
  7. آدرس Web App URL را کپی کنید

⚙️ اتصال به سایت ساز

  1. در پنل: تنظیمات ← ارسال درخواست ← واسط Google Apps Script
  2. فعال‌سازی را بزنید و آدرس Web App را وارد کنید
  3. Bot Token و Chat ID را در بخش «کانال تلگرام (مستقیم)» همان صفحه وارد کنید (این مقادیر به واسط گوگل هم پاس داده می‌شوند)
  4. با دکمه «ارسال مجدد» در یک درخواست، تست کنید

📥 کد کامل اسکریپت (قابل کپی)

function doPost(e) {
  try {
    var params = JSON.parse(e.postData.contents);
    if (!params.bot_token || !params.chat_id || !params.message) {
      return jsonResult({ success: false, error: 'پارامترهای الزامی ارسال نشده' });
    }
    if (params.photo_url) {
      try {
        UrlFetchApp.fetch('https://api.telegram.org/bot' + params.bot_token + '/sendPhoto', {
          method: 'post', contentType: 'application/json', muteHttpExceptions: true,
          payload: JSON.stringify({ chat_id: params.chat_id, photo: params.photo_url, caption: params.caption || '' })
        });
      } catch (err) {}
    }
    var response = UrlFetchApp.fetch('https://api.telegram.org/bot' + params.bot_token + '/sendMessage', {
      method: 'post', contentType: 'application/json', muteHttpExceptions: true,
      payload: JSON.stringify({ chat_id: params.chat_id, text: params.message, parse_mode: 'HTML' })
    });
    var result = JSON.parse(response.getContentText());
    return jsonResult(result.ok
      ? { success: true, message_id: result.result.message_id }
      : { success: false, error: result.description });
  } catch (err) {
    return jsonResult({ success: false, error: err.toString() });
  }
}
function doGet() {
  return jsonResult({ success: true, service: 'Sahand Telegram Bridge' });
}
function jsonResult(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON);
}
