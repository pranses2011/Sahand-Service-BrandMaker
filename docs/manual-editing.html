✏️ راهنمای ویرایش دستی سایت‌های برند

هسته سایت برند PHP خالص است و کاملاً قابل ویرایش دستی — بدون نیاز به سایت ساز.

📁 ساختار فایل‌ها

brand-site/
├── index.php          ← صفحه اصلی
├── config.php         ← ⚠️ تنظیمات اتصال (ویرایش نکنید مگر ضرورت)
├── 404.php            ← صفحه خطای ۴۰۴
├── css/style.css      ← استایل اصلی
├── css/theme-*.css    ← پالت رنگ (تولید خودکار)
├── js/app.js          ← اسکریپت اصلی
├── js/tracker.js      ← ردیاب بازدید
├── pages/             ← ۱۵ صفحه سایت
├── includes/          ← هدر/فوتر/توابع مشترک
├── sitemap.xml        ← تولید خودکار
└── robots.txt         ← تولید خودکار

🎨 تغییر رنگ‌ها

متغیرهای رنگ در css/theme-light.css و css/theme-dark.css قرار دارند:

:root {
    --color-primary: #1e40af;    /* رنگ اصلی برند */
    --color-primary-dark: #1e3a8a;
    --color-accent: #f59e0b;
    /* ... ۱۷ متغیر */
}

📝 ویرایش محتوای صفحات

محتوا از API سایت ساز خوانده و ۵ دقیقه کش می‌شود. برای ویرایش دائمی بدون سایت ساز:

  1. فایل صفحه را باز کنید (مثلاً pages/about-brand.php)
  2. فراخوانی fetchFromAPI را با محتوای HTML ثابت جایگزین کنید
// قبل:
$content = fetchFromAPI('brand/' . BRAND_ID . '/page/about-brand')['data']['content'] ?? [];

// بعد (محتوای ثابت):
$content = ['content' => 'متن دلخواه شما اینجا قرار می‌گیرد...'];

🧹 پاک‌سازی کش

پس از تغییر داده‌ها در سایت ساز، محتوا حداکثر تا ۵ دقیقه بعد بروزرسانی می‌شود. برای بروزرسانی فوری، پوشه cache/ را خالی کنید.

➕ افزودن صفحه جدید

  1. فایلی در pages/ بسازید (کپی از یک صفحه موجود)
  2. در .htaccess یک RewriteRule اضافه کنید
  3. لینک را در منو (از پنل سایت ساز) ثبت کنید

⚠️ نکات مهم

  • فایل config.php حاوی کلید API است — آن را عمومی نکنید
  • پوشه cache/ باید قابل نوشتن باشد (755)
  • آیکون‌ها و فونت‌ها از سرور سایت ساز فراخوانی می‌شوند — اگر مستقل می‌خواهید، فایل‌ها را کپی و آدرس‌ها را تغییر دهید
