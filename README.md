## 🎯 سایت ساز چه می‌کند؟

با دادن **لوگو + نام برند (فارسی/انگلیسی) + دامنه**، یک سایت کامل و حرفه‌ای تولید می‌شود:

| قابلیت | توضیح |
|--------|-------|
| 🎨 استخراج رنگ از لوگو | الگوریتم K-Means → پالت تم روشن + تاریک (۱۷ متغیر CSS) — **پشتیبانی کامل SVG** (استخراج رنگ از fill/stroke بدون Imagick) + fallback نرم |
| ✍️ محتوای یکتا | موتور AI داخلی (بدون API خارجی) — هیچ دو سایتی متن یکسان ندارند |
| 📰 ۵ مقاله اولیه | هر مقاله ۱۰۰۰-۱۵۰۰ کلمه + **۳ تصویر مرتبط** + فهرست مطالب + زمان مطالعه + جعبه نکته/هشدار + مزایا-معایب |
| 🔍 سئوی خودکار | عنوان، متا، Schema (Article/FAQ/HowTo/Speakable)، OG، تراکم کلیدواژه، sitemap، robots + **چک‌لیست E-E-A-T + موجودیت‌ها + خوشه معنایی + شکاف محتوایی** |
| 📦 خروجی ZIP | هسته PHP آماده آپلود + کلید API + پالت رنگ |
| 📨 درخواست خدمات | ارسال ۵ کاناله: ایمیل، تلگرام (مستقیم + واسط گوگل)، بله، 🤖 ربات تلگرام |
| 📊 آمار کامل | ردیاب داخلی + GeoIP محلی ایران + نمودار + نقشه شهرها |
| 🎭 قالب‌ساز | درگ‌اند‌دراپ با ۱۵ دسته بلوک + ۵ طرح برای هر صفحه |
| 🌐 جستجوی آنلاین وب + 📰 اخبار | موتور AI در صورت لزوم از اینترنت داده زنده و اخبار تازه می‌گیرد — **۹ ارائه‌دهنده (ویکی‌پدیا fa/en + Startpage + ...)** با **مسابقه موازی curl_multi** (تأخیر تا ۵۰٪ کمتر) + تشخیص تازگی و اعتماد دامنه |
| 🤖 ربات تلگرام v2.1 | دستیار فارسی کامل در تلگرام + **تحویل مقاله کامل با فایل HTML/Markdown و آلبوم ۳ عکس** + ۱۶ فرمان (جدید: /seo پکیج سئو، /eeat اعتمادسنجی، /plan برنامه محتوا، /faq سوالات متداول) |
| 📱 ریسپانسیو کامل | پنل + سایت‌های برند + نصب — منو، گریدها، جدول‌ها و فرم‌ها در همه ابعاد |

## 🔌 API موتور AI — استفاده از بیرون سایت ساز

موتور AI یک سرویس مستقل با **۳۹ اندپوینت JSON** است که از هر برنامه خارجی (PHP / Python / JavaScript / ربات تلگرام / n8n / Postman) قابل فراخوانی است:

```bash
# 🚀 خط تولید هوشمند — یک فراخوانی = مقاله کامل + سئو + FAQ + تضمین کیفیت
# 🌐 پارامتر research: مقاله با داده‌های زنده وب غنی می‌شود
curl -X POST "https://YOUR-DOMAIN/api/ai/smart-generate" \
  -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" \
  -d '{"brand_id": 1, "device_key": "washing_machine", "target_score": 85, "research": true}'

# 💬 دستیار فارسی — بدون نیاز به یادگیری اندپوینت‌ها
curl -X POST "https://YOUR-DOMAIN/api/ai/assistant" \
  -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" \
  -d '{"command": "کلمات کلیدی ماشین لباسشویی"}'

# 🌐 جستجوی آنلاین اینترنت (جدید v3.1 — بدون نیاز به کلید ارائه‌دهنده)
curl -X POST "https://YOUR-DOMAIN/api/ai/web-search" \
  -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" \
  -d '{"query": "قیمت موتور ماشین لباسشویی", "limit": 5}'

# 🧪 تحقیق ساختاریافته آنلاین — کلیدواژه ترند + سؤالات واقعی + داده تازه
curl -X POST "https://YOUR-DOMAIN/api/ai/research" \
  -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" \
  -d '{"topic": "تعمیر یخچال ساید بای ساید"}'
```
