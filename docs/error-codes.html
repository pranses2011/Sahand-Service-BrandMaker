🚨 راهنمای ورود گروهی کدهای خطا

📊 فرمت فایل Excel (.xlsx)

سطر اول (هدرها) الزامی است. نام ستون‌ها دقیقاً به این صورت باشد:

ستونالزامیتوضیحمثال
device✅نام فارسی دستگاهلباسشویی
code✅کد خطاE1
title✅عنوان مختصرخطای تخلیه آب
description❌شرح کاملدستگاه قادر به تخلیه آب نیست
causes❌دلایل — جدا با | یا ؛گرفتگی فیلتر | خرابی پمپ
solutions❌راه‌حل‌ها — جدا با |تمیز کردن فیلتر | تماس با تعمیرکار
severity❌کم / متوسط / زیاد / بحرانیزیاد
needs_technician❌بله / خیربله

  "error_codes": [

      "description": "دستگاه قادر به تخلیه آب نیست",
      "causes": ["گرفتگی فیلتر تخلیه", "خرابی پمپ تخلیه"],
      "solutions": ["تمیز کردن فیلتر تخلیه", "تماس با تعمیرکار"],
      "severity": "زیاد",
      "needs_technician": true
    }
  ]
}

📥 مراحل ورود

  1. منوی کدهای خطا ← ورود گروهی
  2. برند را انتخاب کنید (یا «عمومی» برای همه برندها)
  3. فایل XLSX یا JSON را انتخاب و «ورود از فایل» بزنید
  4. گزارش نتیجه نمایش داده می‌شود: تعداد ثبت / رد تکراری‌ها / خطاها

🤖 تولید خودکار با AI

با انتخاب برند و کلیک «تولید با AI»، کدهای خطای رایج دستگاه‌های آن برند از پایگاه دانش استخراج و ثبت می‌شوند (مثلاً برای برند با ۶ دستگاه حدود ۲۵-۳۵ کد).

⚠️ نکات

  • کدهای تکراری (همان برند + دستگاه + کد) به صورت خودکار رد می‌شوند
  • مقادیر severity فارسی (کم/متوسط/زیاد/بحرانی) به صورت خودکار معادل انگلیسی ذخیره می‌شوند
  • پارسر Excel داخلی است — بدون هیچ کتابخانه خارجی
