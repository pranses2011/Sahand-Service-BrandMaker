📘 راهنمای کاربری سایت ساز برند سهند سرویس

🏠 داشبورد

نمای کلی سیستم: تعداد برندها، درخواست‌های جدید، بازدید امروز، مقالات، کدهای خطا + نمودار ۷ روزه + وضعیت موتور AI + آخرین درخواست‌ها و فعالیت‌ها.

🏷️ ساخت سایت برند جدید (گام به گام)

  1. مدیریت برندها ← برند جدید
  2. نام فارسی و انگلیسی را وارد کنید (نام انگلیسی برای دامنه و سئو مهم است)
  3. لوگو را آپلود کنید — پالت رنگ سایت به صورت خودکار از لوگو استخراج می‌شود!
  4. دامنه: زیردامنه خودکار (مثل samsung.ea-fixer.ir) یا دامنه اختصاصی
  5. روی «ایجاد برند» کلیک کنید — فرآیند ساخت ۸ مرحله‌ای آغاز می‌شود:
    • 🎨 تحلیل لوگو و استخراج پالت (تم روشن + تاریک)
    • 📚 تطبیق برند با پایگاه دانش ۵۷ برند
    • ✍️ تولید محتوای یکتای تمام صفحات
    • 📰 ۵ مقاله یکتا (اولی فوری + ۴ مقاله زمان‌بندی‌شده)
    • ❓ تولید ۱۰+ سوال متداول
    • 🚨 ثبت کدهای خطای رایج
    • 🔍 بهینه‌سازی سئو + امتیازدهی
    • 🎉 نهایی‌سازی

✏️ ویرایش برند (۶ تب)

🔌 APIکلید API سایت برند (برای اتصال به سایت ساز)

📨 مدیریت درخواست‌ها

درخواست‌های ثبت‌شده در سایت‌های برند به صورت خودکار اینجا نمایش داده می‌شوند و به کانال‌های فعال (ایمیل، تلگرام، بله) ارسال می‌شوند. وضعیت‌ها: جدید ← در حال بررسی ← تخصیص یافته ← انجام شده / لغو شده.

📰 تولید مقاله با AI

از منوی مقالات ← «تولید جدید»: برند + نوع مقاله (رفع ایراد/راهنما/نگهداری/مقایسه/کدهای خطا) + دستگاه را انتخاب کنید. موتور AI مقاله‌ای یکتا (۸۰۰-۱۵۰۰ کلمه) با ساختار H2/H3، لینک داخلی و سئو تولید می‌کند.

🎭 قالب‌ساز درگ‌اند‌دراپ

  1. از منوی قالب‌ها، قالب مورد نظر را ویرایش کنید یا جدید بسازید
  2. بلوک‌ها را از پنل راست به بوم بکشید (یا دابل‌کلیک کنید)
  3. با درگ روی هم مرتب کنید — دکمه ⋯ زیرمنو می‌سازد
  4. ویژگی‌های هر بلوک (فاصله/پس‌زمینه/عنوان) را در پنل چپ تنظیم کنید
  5. ذخیره کنید — ۵ طرح پیش‌فرض برای هر صفحه موجود است

🖼️ آیکون‌ها و 🔤 فونت‌ها

۱۰ پک آیکون (شامل ۱۰۳ آیکون اختصاصی لوازم خانگی) روی سرور سایت ساز ذخیره شده‌اند. فایل‌های فونت (woff2/ttf) را از صفحه فونت‌ها آپلود کنید — تعریف ۱۳۴ وزن از قبل آماده است.

📦 خروجی و استقرار

از منوی خروجی، برند را انتخاب و ZIP بسازید. فایل شامل هسته کامل + کلید API + پالت رنگ + sitemap.xml و robots.txt خودکار است. راهنمای آپلود روی هاست در همان صفحه موجود است.
