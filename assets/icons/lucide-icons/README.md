# 📦 پک لوسید آیکون (Lucide)

این پک با زیرمجموعه‌ای از آیکون‌های پرکاربرد ارائه می‌شود (8 آیکون موجود).
پک کامل (۱۵۰۰+ آیکون) را از لینک‌های رسمی زیر دانلود و از طریق
**پنل مدیریت → آیکون‌ها → ایمپورت پک** بارگذاری کنید.

## 📥 لینک‌های دانلود رسمی

| منبع | لینک |
|------|------|
| 🌐 سایت رسمی (مرور + دانلود تک‌تک) | [https://lucide.dev/icons](https://lucide.dev/icons) |
| 📦 مخزن GitHub (کد منبع) | [https://github.com/lucide-icons/lucide](https://github.com/lucide-icons/lucide) |
| 🚀 **دانلود مستقیم آخرین نسخه (ZIP)** | [**https://github.com/lucide-icons/lucide/releases/latest**](https://github.com/lucide-icons/lucide/releases/latest) |

> ⚡ **سریع‌ترین راه:** روی لینک «دانلود مستقیم» بزنید — در صفحه بازشده، فایل ZIP آماده
> آخرین نسخه (مثل `remixicon-4.x.x.zip`) در پایین است. فایل `icons/` داخل آن را
> از طریق پنل ایمپورت کنید.

## ℹ️ مشخصات

| مورد | مقدار |
|------|-------|
| تعداد آیکون پک کامل | ۱۵۰۰+ |
| لایسنس | ISC (کاملاً آزاد) |
| ویژگی | جانشین مدرن Feather با آیکون‌های بسیار بیشتر |
| موجود در این ریپو | 8 آیکون پرکاربرد |

## 🔒 نکات
- آیکون‌ها روی سرور سایت ساز ذخیره می‌شوند (بدون CDN خارجی)
- فرمت استاندارد: SVG با viewBox=24x24
