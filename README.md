## 🎯 سایت ساز چه می‌کند؟

با دادن **لوگو + نام برند (فارسی/انگلیسی) + دامنه**، یک سایت کامل و حرفه‌ای تولید می‌شود:

| قابلیت | توضیح |
|--------|-------|
| 🎨 استخراج رنگ از لوگو | الگوریتم K-Means → پالت تم روشن + تاریک (۱۷ متغیر CSS) |
| ✍️ محتوای یکتا | موتور AI داخلی (بدون API خارجی) — هیچ دو سایتی متن یکسان ندارند |
| 📰 ۵ مقاله اولیه | هر مقاله ۸۰۰-۱۵۰۰ کلمه + زمان‌بندی انتشار |
| 🔍 سئوی خودکار | عنوان، متا، Schema.org، OG، sitemap، robots + امتیازدهی |
| 📦 خروجی ZIP | هسته PHP آماده آپلود + کلید API + پالت رنگ |
| 📨 درخواست خدمات | ارسال ۴ کاناله: ایمیل، تلگرام (مستقیم + واسط گوگل)، بله |
| 📊 آمار کامل | ردیاب داخلی + GeoIP محلی ایران + نمودار + نقشه شهرها |
| 🎭 قالب‌ساز | درگ‌اند‌دراپ با ۱۵ دسته بلوک + ۵ طرح برای هر صفحه |

## ⚡ نصب سریع (۵ دقیقه)

```bash
# ۱. کل ریپو را روی هاست cPanel در زیردامنه brandmaker آپلود کنید
# ۲. یک دیتابیس MySQL بسازید
# ۳. در مرورگر باز کنید:
https://brandmaker.ea-fixer.ir/install.php
# ۴. اطلاعات دیتابیس + حساب مدیر → نصب خودکار ✅
```

```
│   ├── analyzers/       ← رنگ(K-Means)، یکتایی، کلیدواژه، سئو
│   └── knowledge/       ← پایگاه دانش ۵۷ برند + ۳۲ دستگاه

├── templates/brand-core/ ← هسته سایت برند (۳۳ فایل) — قالب ZIP

```

## 🤖 موتور AI داخلی نسخه ۲ — بدون هیچ API خارجی

موتور با ترکیب ۶ روش محتوای یکتا تولید می‌کند:
1. انتخاب قالب از ۱۲+ قالب هر نوع (seeded random)
2. جایگذاری داده‌های واقعی برند از پایگاه دانش
3. جایگزینی مترادف (۴۷۵ واژه) + بازنویسی عبارات چندکلمه‌ای (۶۰ عبارت)
4. بازنویسی ساختار جملات
5. بررسی یکتایی (Jaccard سه‌گرامی — شباهت زیر ۳۵٪)
6. بهینه‌سازی سئو (کلیدواژه، هدینگ، لینک داخلی)

**قابلیت‌های نسخه ۲ (v2.0):**
- 🏆 **امتیاز کیفیت ۷ بُعدی** — هر محتوا قبل از تحویل امتیاز ۰-۱۰۰ می‌گیرد (QualityScorer)
- 🎰 **بهترین-از-N** — تولید چند واریانت و انتخاب بهترین مقاله
- 🧭 **تشخیص نیت جستجو** — اطلاعاتی / تجاری / تراکنشی / ناوبری (IntentClassifier)
- 🗓️ **تقویم محتوای هوشمند** — برنامه انتشار فصلی با اولویت‌بندی (ContentPlanner)
- 📰 **۹ نوع مقاله** — از جمله مراقبت فصلی و راهنمای هزینه + جعبه TL;DR + FAQ + Schema
- 📊 **سئوی ۲۶ بررسی** — شامل E-E-A-T، انسجام، اسکیما و خوانایی
- 🧮 **TF-IDF + خوشه‌بندی + رقابت‌پذیری** کلیدواژه‌ها
- 🌱 **ریشه‌یاب فارسی** و سنجش خوانایی هفت‌متریکه

**پایگاه دانش:** ۷۷ برند (۳۱۶ فکت تاریخی) + ۴۲ دستگاه (۴۸۳ ایراد رایج) + ۱۲۵ کد خطا + ۲۱ سناریوی عیب‌یابی + ۲۰ قطعه یدکی + تقویم فصلی ۱۲ ماه + مناطق ۱۰ شهر

## 🔐 امنیت

- Prepared Statements (ضد SQL Injection)
- CSRF توکن در تمام فرم‌ها + هدر AJAX
- پاکسازی XSS (ورودی و خروجی + SVG)
- CAPTCHA + قفل ۵ تلاش + محدودیت نرخ (۱۲۰/دقیقه)
- آپلود امن (MIME واقعی + امضای باینری + ضد traversal)
- رمزنگاری BCRYPT + نشست امن (httponly, samesite, regeneration)
