## 🎯 سایت ساز چه می‌کند؟

با دادن **لوگو + نام برند (فارسی/انگلیسی) + دامنه**، یک سایت کامل و حرفه‌ای تولید می‌شود:

| قابلیت | توضیح |
|--------|-------|
| 🎨 استخراج رنگ از لوگو | الگوریتم K-Means → پالت تم روشن + تاریک (۱۷ متغیر CSS) |
| ✍️ محتوای یکتا | موتور AI داخلی (بدون API خارجی) — هیچ دو سایتی متن یکسان ندارند |
| 📰 ۵ مقاله اولیه | هر مقاله ۸۰۰-۱۵۰۰ کلمه + زمان‌بندی انتشار |
| 🔍 سئوی خودکار | عنوان، متا، Schema.org، OG، sitemap، robots + امتیازدهی |
| 📦 خروجی ZIP | هسته PHP آماده آپلود + کلید API + پالت رنگ |
| 📨 درخواست خدمات | ارسال ۴ کاناله: ایمیل، تلگرام (مستقیم + واسط گوگل)، بله |
| 📊 آمار کامل | ردیاب داخلی + GeoIP محلی ایران + نمودار + نقشه شهرها |
| 🎭 قالب‌ساز | درگ‌اند‌دراپ با ۱۵ دسته بلوک + ۵ طرح برای هر صفحه |

## ⚡ نصب سریع (۵ دقیقه)

```bash
# ۱. بسته نصب را از صفحه Releases دانلود کنید (یا کل ریپو را آپلود کنید)

# ۳. یک دیتابیس MySQL بسازید
# ۴. در مرورگر باز کنید:
https://brandmaker.your-domain.ir/install.php
# ۵. اطلاعات دیتابیس + حساب مدیر → نصب خودکار ✅
```

## 🤖 موتور AI داخلی نسخه ۳ «بی‌رقیب» — بدون هیچ API خارجی

موتور با ترکیب ۶ روش محتوای یکتا تولید می‌کند: انتخاب قالب seeded، جایگذاری دانش واقعی برند، جایگزینی مترادف (۴۷۵ واژه)، بازنویسی عبارت و ساختار، بررسی یکتایی (شباهت زیر ۳۵٪)، بهینه‌سازی سئو.

### 🚀 قابلیت‌های جدید نسخه ۳ (v3.0)

| قابلیت | توضیح |
|--------|-------|
| 🧠 **خط تولید هوشمند** | یک فراخوانی = ۸ مرحله خودکار: نیت ← کلیدواژه ← مقاله بهترین-از-N ← بهبود خودکار ← عنوان بهینه ← سئو ← FAQ/اسکیما ← یکتایی |
| 🔧 **بهبود خودکار محتوا** | چرخه خود-درمانی: شناسایی ابعاد ضعیف و اعمال ۷ استراتژی هدفمند تا رسیدن به امتیاز هدف — با ضمانت عدم تخریب |
| 🎙️ **تحلیل صدای برند** | پروفایل لحن (رسمیت/فنی/محاوره) + ۴ تیپ صدا + سنجش انسجام متن جدید با صدای برند |
| 🏷️ **عنوان‌ساز CTR-محور** | ۸ الگوی عنوان + امتیازدهی طول/عدد/سؤال/واژه قدرت/موقعیت کلیدواژه |
| 💬 **دستیار فرمان فارسی** | رابط زبان طبیعی: «مقاله بنویس برای اسنوا درباره لباسشویی» → اجرای خودکار |
| ⚡ **کش موتور** | پاسخ‌های پرتکرار آنی — TTL + آمار hit/miss + پاکسازی |

### 🧠 قابلیت‌های نسخه ۲ (همچنان فعال)

🏆 امتیاز کیفیت ۷ بُعدی | 🎰 بهترین-از-N | 🧭 تشخیص نیت جستجو | 🗓️ تقویم محتوای هوشمند | 📰 ۹ نوع مقاله | 📊 سئوی ۲۶ بررسی | 🧮 TF-IDF و خوشه‌بندی | 🌱 ریشه‌یاب فارسی

### 📚 پایگاه دانش

## 🔌 API موتور AI — استفاده از بیرون سایت ساز

موتور AI یک سرویس مستقل با **۳۴ اندپوینت JSON** است که از هر برنامه خارجی (PHP / Python / JavaScript / ربات تلگرام / n8n / Postman) قابل فراخوانی است:

```bash
# 🚀 خط تولید هوشمند — یک فراخوانی = مقاله کامل + سئو + FAQ + تضمین کیفیت
curl -X POST "https://YOUR-DOMAIN/api/ai/smart-generate" \
  -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" \
  -d '{"brand_id": 1, "device_key": "washing_machine", "target_score": 85}'

# 💬 دستیار فارسی — بدون نیاز به یادگیری اندپوینت‌ها
curl -X POST "https://YOUR-DOMAIN/api/ai/assistant" \
  -H "Content-Type: application/json" -H "X-API-Key: YOUR_KEY" \
  -d '{"command": "کلمات کلیدی ماشین لباسشویی"}'
```

📖 **مرجع کامل:** [`docs/AI-API-GUIDE.md`](docs/AI-API-GUIDE.md) — ۱۳۰۰+ خط مستندات فارسی با مثال‌های واقعی به ۴ زبان

## 🔐 امنیت

- Prepared Statements (ضد SQL Injection)
- CSRF توکن در تمام فرم‌ها + هدر AJAX
- پاکسازی XSS (ورودی و خروجی + SVG)
- CAPTCHA + قفل ۵ تلاش + محدودیت نرخ (۱۲۰/دقیقه)
- آپلود امن (MIME واقعی + امضای باینری + ضد traversal)
- رمزنگاری BCRYPT + نشست امن (httponly, samesite, regeneration)
