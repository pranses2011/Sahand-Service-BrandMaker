# 📦 پک فدر آیکون (Feather Icons)

این پک با زیرمجموعه‌ای از آیکون‌های پرکاربرد ارائه می‌شود (8 آیکون موجود).
پک کامل (۲۸۰+ آیکون) را از لینک‌های رسمی زیر دانلود و از طریق
**پنل مدیریت → آیکون‌ها → ایمپورت پک** بارگذاری کنید.

## 📥 لینک‌های دانلود رسمی

| منبع | لینک |
|------|------|
| 🌐 سایت رسمی (مرور + دانلود تک‌تک) | [https://feathericons.com](https://feathericons.com) |
| 📦 مخزن GitHub (کد منبع) | [https://github.com/feathericons/feather](https://github.com/feathericons/feather) |
| 🚀 **دانلود مستقیم آخرین نسخه (ZIP)** | [**https://github.com/feathericons/feather/releases/latest**](https://github.com/feathericons/feather/releases/latest) |

> ⚡ **سریع‌ترین راه:** روی لینک «دانلود مستقیم» بزنید — در صفحه بازشده، فایل ZIP آماده
> آخرین نسخه (مثل `remixicon-4.x.x.zip`) در پایین است. فایل `icons/` داخل آن را
> از طریق پنل ایمپورت کنید.
