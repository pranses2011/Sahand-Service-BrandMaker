# 📦 پک فدر آیکون (feather-icons)

این پک با زیرمجموعه‌ای از آیکون‌های پرکاربرد ارائه می‌شود (8 آیکون).
پک کامل (۲۸۰+ آیکون) را می‌توانید از مخزن رسمی دانلود و از طریق
**پنل مدیریت → آیکون‌ها → ایمپورت پک** بارگذاری کنید.

## 📥 منابع رسمی دانلود
- آیکون‌های SVG از مخزن رسمی پک مربوطه
- آپلود فایل ZIP از طریق پنل — سیستم به صورت خودکار SVG ها را ایندکس می‌کند

## 🔒 نکات
- آیکون‌ها روی سرور سایت ساز ذخیره می‌شوند (بدون CDN خارجی)
- فرمت استاندارد: SVG با viewBox=24x24
